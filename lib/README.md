# Bundled libraries / 附带的库

| 文件 | 来源 | 许可 |
|---|---|---|
| `HIDMaestro.Core.dll` | [HIDMaestro](https://github.com/hifihedgehog/HIDMaestro)（release 构建） | MIT — 见 [`LICENSE-HIDMaestro.txt`](LICENSE-HIDMaestro.txt) |
| `Microsoft.Windows.SDK.NET.dll` | Microsoft（C#/WinRT，Windows SDK 投影） | MIT |
| `WinRT.Runtime.dll` | Microsoft（C#/WinRT 运行时） | MIT |

`HIDMaestro.Core.dll` 为第三方库，按 MIT 许可要求**随附其许可证全文**（`LICENSE-HIDMaestro.txt`，与 DLL 并排）。

`Microsoft.Windows.SDK.NET.dll` 与 `WinRT.Runtime.dll` 是 `HIDMaestro.Core.dll` 的运行期依赖，
来自微软 [C#/WinRT](https://github.com/microsoft/CsWinRT)（MIT），版权归 Microsoft 所有。
